# Vector Studio: Herramientas de Edición Manual Vectorial y Branding
Basado en el informe comparativo (Figma, Illustrator, Affinity Designer).

## Capacidades:
1. **Redes Vectoriales Dinámicas (Figma)**: Trazado de nodos multi-direccionales y bifurcaciones.
2. **Creador de Formas (Shaper Tool - Illustrator)**: Fusión y recorte intuitivo de geometrías.
3. **Pluma y Curvas Bezier (Pen Tool)**: Inserción de anclas y curvatura de vectores.
4. **Operaciones Booleanas (Buscatrazos)**:
   - Unir (Union)
   - Restar (Subtract)
   - Intersectar (Intersect)
   - Excluir (Exclude)
5. **Alternancia Persona Vector / Píxel (Affinity Designer)**:
   - Modo Vectorial: Nodos limpios, SVG matemáticos.
   - Modo Píxel: Pinceles texturizados, mapa de bits y acabado artesanal / grunge.
